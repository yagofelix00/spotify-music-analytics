# Spotify Music Analytics

Projeto de análise de dados musicais utilizando dados da Spotify Web API.

## Objetivo

Coletar, transformar e analisar dados de músicas, artistas e álbuns utilizando Python e Pandas, evoluindo posteriormente para análises em SQL e visualizações em Power BI.

## Tecnologias

- Python
- Pandas
- Spotify Web API
- Spotipy
- Jupyter
- PostgreSQL
- Power BI
